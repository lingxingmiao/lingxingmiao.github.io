关于 Translator Minecraft

使用大语言模型翻译 Minecraft 与 CasualtiesUnknown 中的各类内容。基于大语言模型与高级检索增强生成（RAG）技术， 把整合包 / 模组 / 任务 / 资源包 / 光影包的汉化流程压缩成「上传一个文件」。

支持的内容

  • 整合包 / 模组 / 数据包
  • 资源包 / 光影包
  • FTB 任务 / 更好的任务(BQ) / 困难任务
  • 帕秋莉手册
  • CraftTweaker(displayName / tooltip)
  • 自定义主菜单 / 精致菜单
  • 核电工艺重制版附加包
  • 未知伤亡语言文件(CasualtiesUnknown)
  • BepInEx 插件 / 模组翻译 / TX Loader
  • SFT 数据集(用于蒸馏)

本网站

公益站点，只提供翻译功能，免费、不限量、不限速，输出语言固定为中文（需要其它输出语言请直接调用 API）。 可上传 .jar / .zip / .mrpack / .lang / .json / .zs / .dll / .txt，每个文件算一个任务，最多同时提交 3 个（可在设置里改）。 单个文件上限 95MB（Cloudflare 免费版单请求上限 100MB），更大的文件请上传到 QQ 群 606269975。 上传的参考文件用于差异对比，会把已有译文作为参考词。

API

公益 API：https://api.tanslamc.top，密钥 sk-123456， 请求格式与端点见仓库里的 TranslatorAPI.py。该 API 可自定义输出语言。

运行环境

本地跑完整程序需要 64 位系统、支持 AVX2 的处理器、8GB 内存、支持 Vulkan 1.2（显存 ≥ 4GB）的显卡，约 4GB 硬盘空间； 推荐 24GB 内存 + RTX 3060 12GB。翻译模型可选 DeepSeek / Qwen / Xiaomi MiMo / Ornith / Qwopus 等系列， 嵌入模型 BGE-Base-EN-v1.5，向量搜索 NSGSQ8 + Refine，支持极限向量压缩。
